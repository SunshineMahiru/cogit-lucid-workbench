## 亮点

- **元认知外化** —— 把原本手动运行的「记录 → 分析 → 校准 → 锚点对照」循环，搬到软件上。
- **预测日志** —— 判断事前落盘、禁止事后修改、到期结算、统计命中率。
- **本地优先** —— 原始记录留在设备本地；LLM 调用即时即弃、可选开启。
