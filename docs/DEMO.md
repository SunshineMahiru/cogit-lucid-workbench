# 演示步骤与截图

本文件用于课程演示与截图核对。截图全部来自模拟器与本机合成数据，画面中没有真实姓名、真实关系人、真实预测或真实锚点。

## 一、演示路径

按下面的顺序走一遍，约 6 分钟。每一步先说「这一屏要证明什么」，再点。

### 1. 首页：先记录，不急着解释

- 页面：`docs/images/shot_home.jpeg`
- 操作：打开应用，停在首页。
- 讲解：身份区可以留空（显示「未命名」）；四个入口分别是记录此刻、待校正、当前计划、全部模块；下面依次是当日读数、总速记与待结算、本周结算、当前计划、本期提示。
- 要证明：首页不要求填身份，功能完整；记录入口在首屏。

### 2. 复盘：六区表单，写一区就能保存

- 页面：`docs/images/shot_review.jpeg`
- 操作：全部模块 → 复盘 → 周复盘，停在第一区。
- 讲解：六区依次是现场与既有行动、当前模型、关系与主要矛盾、多源校正、成本与动机、调节与修订；只写第一区也能保存，留空的区在详情里显示「未填写」。
- 要证明：复盘不再强制四步走完，空白复盘合法。

### 3. 预测统计：五档结算，只有两档进命中率

- 页面：`docs/images/shot_stats.jpeg`
- 操作：全部模块 → 预测 → 统计。
- 讲解：整体命中率 0%，已结算 1 条，命中 0、未命中 0；下方五档为成立 0、未成立 0、部分成立 1、证据不足 0、无法判断 0；样本不足 10 条时只提示「校准结果仅供观察」。
- 要证明：部分成立不进分母，命中率不被非二值结果拉低；页面写明「数据来自本机预测记录」。

### 4. 关系：披露与引用边界

- 页面：`docs/images/shot_relation.jpeg`
- 操作：全部模块 → 关系 → 朋友 A。
- 讲解：层级只说明能谈到哪一层；卡片写明「可以记录真实想法与对方的明确表态；对方的话默认只留在本机」，并写明不推断动机、人格与关系结局；下方是「对方怎样纠正了我的理解」。
- 要证明：关系模块不提供动机分析许可，只描述可分享范围。

### 5. 状态：身体证据与观察规则

- 操作：全部模块 → 状态 → ＋。
- 讲解：睡眠、运动、凌晨报警可逐项标「不清楚」；另记身体信号、当下功能、情绪、环境；承受判断由本人从四项里选；下方是功能与成本两条；底部两个出口是「只保存，不处理」与「保存并暂停计划」。
- 要证明：读数缺项不影响保存，系统不替人判断能否继续。

### 6. 导出：先选内容，再写文件

- 页面：`docs/images/shot_export.jpeg`
- 操作：设置 → 导出。
- 讲解：五类内容去向逐条列出；可分析内容始终写入；仅本地、对方陈述原文、示例数据默认「不纳入」；封存内容始终不写入；勾选前两类时，导出前会弹「文件会离开应用沙箱」。
- 要证明：导出前就知道每一类会写到哪里，封存内容没有入口。

### 7. 备份：逐类结果与安全副本

- 页面：同 `docs/images/shot_export.jpeg` 下半部分。
- 讲解：备份包含记录、身份与设置，封存内容只留本机；背景图片默认不包含；本机安全副本 6 份，最近时间与清理入口都在。
- 要证明：恢复失败不会被一句「成功」盖住，恢复前有可回退副本。

### 8. 背景：对比度自检

- 页面：`docs/images/shot_contrast.jpeg`
- 操作：设置 → 页面背景 → 背景浓淡。
- 讲解：默认 10% 时显示「正文对比度最低 9.9:1，满足 4.5:1，任意图片下都可读」；调高浓淡读数下降并给出建议；下方有「恢复默认纯色底」。
- 要证明：外观改造服从阅读，个人图片不进入导出与备份。

## 三、演示前检查

1. 设置里模型档位停在「模板」或「本地模拟」，不要指向真实端点。
2. 关系列表只有化名（朋友 A、同事 B、家人 C）。
3. 预测日志里没有真实姓名与真实事件。
4. 备份与导出目录里没有旧文件残留。
5. 关闭开发者选项里的调试入口再截图。
