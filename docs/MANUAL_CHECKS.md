# 人工核对清单

记录日期：2026-11-13，构建 `62d4d62`，设备 Mate 70 Pro 模拟器。

自动化覆盖不到的部分记在这里，写清步骤与结果，方便下次改动后照着复跑。

## 为什么有些东西测不了

| 限制 | 影响 |
|---|---|
| 设备端 `Driver.swipe` 与 `Component.scrollSearch` 调用不返回，并抛 `uitest-api dose not allow calling concurrently` | 需要滚动才能到达的控件无法自动点击 |
| 系统标题栏的返回箭头没有 id 也没有文本，`pressBack()` 在输入框有焦点时会被输入法吞掉 | 返回拦截只能手动点标题栏箭头触发 |
| 键盘弹出后，同一位置的第一次点击只用于收起键盘 | 自动化点击表单按钮时常需要连点两次；`uitest uiInput inputText` 可直接落字，不受此影响 |

这两条都实测过两次以上，不是偶发。改动相关代码后，靠下面的清单人工回归。

## 一、离开未保存表单时的确认

四个编辑页各自有一个 `isDirty` 与 `onDestinationBackPressed`。验证方法是：改动任意字段 → 点标题栏左上角返回箭头 → 应弹确认框 → 选「放弃」应回到列表且改动未入库。

| 页面 | 结论 | 核对日期 |
|---|---|---|
| 预测新建 | 弹「放弃这条预测？」，放弃后列表无新增 | 2026-11-13 |
| 关系编辑 | 弹「放弃这条关系？」，放弃后列表仍为 3 人 | 2026-11-13 |
| 状态读数 | 弹「放弃这条读数？」，放弃后读数未增加 | 2026-11-13 |
| 计划编辑 | 弹「放弃这个目标？」，放弃后名称仍为「验收计划1109」 | 2026-11-13 |

注意两点：

- 必须点标题栏的返回箭头，不要按系统返回键——输入框有焦点时按键会被输入法吃掉，看起来像“拦没生效”。
- 未改动内容时点返回应当直接返回，不弹框。计划页这一条已核对。

## 二、布局走查

间距与圆角统一之后逐页看过，检查项是：文字不被裁切、卡片内距均匀、图表刻度与网格线对齐、系统标题栏的菜单项不挤压。

覆盖页面：首页、设置、数据看板（首屏 / 中段 / 热力图）、速记列表与编辑、周结算、复盘四步与历史、计划列表与详情、状态面板、关系列表 / 详情 / 星图、预测列表与统计空态。

结论：无裁切、无重叠。图表页的 Y 轴缩进与列表底部留白是刻意保留的字面量，改动这两处要重新看一遍。

## 三、导出链路

设置页「导出并另存为」→ 系统保存对话框 → 确认。检查文件落到 Download、文件名带时间戳、文件头的记录统计与实际条目数一致。

2026-11-13 实测：`cogit-export-20261113-0306.md`，1992 字符、21 条记录，文件头统计与正文一致。

## 四、状态证据与观察规则

1. 状态面板点「＋」，睡眠填 5.5，运动点「不清楚」，报警填 0。
2. 身体信号、当下功能各写一句；承受判断选「需要限量」；功能与成本各写一条。
3. 点「只保存，不处理」，回到面板：应显示「我的判断：需要限量」「身体信号：…」「运动 未记录」。
4. 再点「＋」，改承受判断后保存；历史页应出现「更正 1 次 · 看原读数」，展开可见原读数与原因。
5. 面板「观察规则 ›」把睡眠下限改为 7，保存后提示应写「低于观察下限 7 小时」；点「恢复默认」回到 6.5。

2026-11-15 实测：五步均通过，面板读数与历史一致。

## 五、关系互动来源与引用范围

1. 关系详情「互动记录」先选「对方明确陈述」，引用范围保持「仅本机」。
2. 写一句对方的话并添加；条目应带「对方明确陈述」「仅本机」「不进上下文」三个标签。
3. 点引用标签循环到「可原文引用」，点上下文标签切到「允许」；退出再进入，两个状态应保留。
4. 编辑关系，填写「对方怎样纠正了我的理解」并保存；详情应出现同名卡片，编辑页应回填。

2026-11-15 实测：四步均通过；编辑页标题由「新建关系」修正为「编辑关系」。

## 六、导出清单与备份范围

1. 设置页导出区块应列出五类内容去向，三个开关默认「不纳入」。
2. 勾选「仅本地内容」后点导出，应弹「文件会离开应用沙箱」；取消后开关状态保留。
3. 备份范围里「备份包含背景图片」默认「不包含」；切换后重启仍保留。
4. 勾选与取消都试一遍，确认弹窗只在与仅本地或对方陈述有关时出现。

2026-11-15 实测：四步均通过。

## 七、背景对比度

1. 设置 → 页面背景 → 背景浓淡区域应显示「正文对比度最低 x.x:1」。
2. 把浓淡拉到最高，读数应下降；低于 4.5:1 时文案改为「建议调淡图片或换纯色底」。
3. 点「恢复默认纯色底」应弹确认，确认后清除全部背景并把浓淡重置为 10%。

2026-11-15 实测：默认 10% 显示 9.9:1；恢复入口可用。

## 八、编辑已有速记的材料

模拟器恢复后补跑，按下面步骤核对：

1. 新建一条自由速记，正文写一句，在「分类补充」填现场与感受，保存。
2. 详情页应出现「材料」区，两条材料分别带类型、来源、文体与密级；没有点过文体的材料显示「未标注」。
3. 点「编辑」，正文、现场、感受、来源、文体、密级都应回填；把现场改成另一句，来源选「阅读」，文体选「对话」，再填一条身体，保存。
4. 详情页材料区应只剩改后的现场与新增的身体，来源与文体与选择一致；标签和关联关系仍在。
5. 再编辑一次，把记录密级改成「仅本地」：材料密级一行不应出现「可分析」；保存后每条材料的密级都不宽于记录。

## 九、速记三档深度、草稿恢复与最近标签

1. 普通档填类别、标签、分类补充与密级；切到「快速」，类别、模板字段、标签、分类补充与密级区都应消失，只剩正文、类型 chip 与保存条；切回「普通」，已填内容仍在。
2. 切到「深入」，解释行、关联关系与「新建一条可检验预测」应出现；点该行进入预测新建。
3. 新建速记写一句后点返回箭头选「放弃」，再进入速记：应出现「上次没写完的草稿还在」，正文与其余表单不渲染；点「继续上次草稿」应回填并展开表单。
4. 重复第 3 步，改点「重新开始」：表单为空，再进速记不再出现恢复面板。
5. 保存一条带标签的速记，再新建一条：标签区最近标签行应出现该标签，点击后加入本条；已加入的标签不再出现在最近行。

## 十、什么时候重跑

改了下面任何一处，跑对应小节：

| 改动位置 | 重跑 |
|---|---|
| 四个编辑页的 `isDirty` 或 `onDestinationBackPressed` | 第一节 |
| `AppTheme` 的字号、圆角、间距令牌 | 第二节 |
| `export/` 或设置页的导出入口 | 第三节、第六节 |
| `status/` 或状态页观察规则 | 第四节 |
| `relation/` 或关系详情互动表单 | 第五节 |
| `theme/Contrast.ts` 或背景页浓淡区 | 第七节 |
| 速记编辑的材料区、材料密级 chip、详情材料区 | 第八节 |
| 速记编辑的深度 chip、草稿恢复面板、最近标签行 | 第九节 |
