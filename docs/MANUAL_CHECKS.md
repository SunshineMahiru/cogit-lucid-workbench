# 人工核对清单

记录日期：2026-11-13，构建 `62d4d62`，设备 Mate 70 Pro 模拟器。

自动化覆盖不到的部分记在这里，写清步骤与结果，方便下次改动后照着复跑。

## 为什么有些东西测不了

| 限制 | 影响 |
|---|---|
| 设备端 `Driver.swipe` 与 `Component.scrollSearch` 调用不返回，并抛 `uitest-api dose not allow calling concurrently` | 需要滚动才能到达的控件无法自动点击 |
| 系统标题栏的返回箭头没有 id 也没有文本，`pressBack()` 在输入框有焦点时会被输入法吞掉 | 返回拦截只能手动点标题栏箭头触发 |

这两条都实测过两次以上，不是偶发。改动相关代码后，靠下面的清单人工回归。

## 一、离开未保存表单时的确认

四个编辑页各自有一个 `isDirty` 与 `onDestinationBackPressed`。验证方法是：改动任意字段 → 点标题栏左上角返回箭头 → 应弹确认框 → 选「放弃」应回到列表且改动未入库。

| 页面 | 结论 | 核对日期 |
|---|---|---|
| 预测新建 | 弹「放弃这条预测？」，放弃后列表无新增 | 2026-11-13 |
| 关系编辑 | 弹「放弃这条关系？」，放弃后列表仍为 3 人 | 2026-11-13 |
| 状态读数 | 弹「放弃这条读数？」，放弃后读数未增加 | 2026-11-13 |
| 计划编辑 | 弹「放弃这个目标？」，放弃后名称仍为「验收计划1109」 | 2026-11-13 |

注意两点：

- 必须点标题栏的返回箭头，不要按系统返回键——输入框有焦点时按键会被输入法吃掉，看起来像“拦没生效”。
- 未改动内容时点返回应当直接返回，不弹框。计划页这一条已核对。

## 二、布局走查

间距与圆角统一之后逐页看过，检查项是：文字不被裁切、卡片内距均匀、图表刻度与网格线对齐、系统标题栏的菜单项不挤压。

覆盖页面：首页、设置、数据看板（首屏 / 中段 / 热力图）、速记列表与编辑、周结算、复盘四步与历史、计划列表与详情、状态面板、关系列表 / 详情 / 星图、预测列表与统计空态。

结论：无裁切、无重叠。图表页的 Y 轴缩进与列表底部留白是刻意保留的字面量，改动这两处要重新看一遍。

## 三、导出链路

设置页「导出并另存为」→ 系统保存对话框 → 确认。检查文件落到 Download、文件名带时间戳、文件头的记录统计与实际条目数一致。

2026-11-13 实测：`cogit-export-20261113-0306.md`，1992 字符、21 条记录，文件头统计与正文一致。

## 四、什么时候重跑

改了下面任何一处，跑对应小节：

| 改动位置 | 重跑 |
|---|---|
| 四个编辑页的 `isDirty` 或 `onDestinationBackPressed` | 第一节 |
| `AppTheme` 的字号、圆角、间距令牌 | 第二节 |
| `export/` 或设置页的导出入口 | 第三节 |
